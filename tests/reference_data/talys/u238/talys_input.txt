# Non-default keywords (everything else is a TALYS default):
#   energy        incident LAB neutron energies from file (117 points, 1 keV - 20 MeV)

#   outtransenergy y : group transmission coefficients per energy (explicit; documented default is y)
#   transpower    20 : do not drop small T_lj in the Hauser-Feshbach sum (default 5 drops T_lj < 1e-5/(2l+1) * T_0)
#   transeps      1.e-14 : likewise remove the absolute cutoff on T (default 1e-8)
